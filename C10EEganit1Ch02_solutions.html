1. Key concepts and formulae

Standard form

ax² + bx + c = 0, where a, b, c are real numbers and a ≠ 0.

Quadratic formula

x = (−b ± √(b² − 4ac)) / (2a).

Discriminant and nature of roots

Δ = b² − 4ac. If Δ > 0, roots are real and unequal; if Δ = 0, roots are real and equal; if Δ < 0, roots are not real.

Relations between roots and coefficients

For roots α and β of ax² + bx + c = 0: α + β = −b/a and αβ = c/a.

Equation from roots

If the roots are α and β, the monic quadratic equation is x² − (α + β)x + αβ = 0.

Important restriction

When an equation contains 1/x or another denominator, note the values that make the denominator zero before multiplying through.

For y² = 2y − 7: y² − 2y + 7 = 0, so a = 1, b = −2, c = 7. For x² + 2x = 0: x² + 2x + 0 = 0, so a = 1, b = 2, c = 0.

Sum = −10 and product = 21. Equation: x² + 10x + 21 = 0.

Complete-square example: x² + 10x + 2 = 0

3. Practice Set 2.1

Q1. Write any two quadratic equations

Examples: x² + 5x + 6 = 0 and 2m² − 3m + 1 = 0. Other valid examples are possible.

Q2(1). x² + 5x − 2 = 0

Yes, it is quadratic; its highest power is 2.

Q2(2). y² = 5y − 10

Yes. Standard form: y² − 5y + 10 = 0.

Q2(3). y² + 1/y = 2

As written, it contains a reciprocal. Multiplying by y (y ≠ 0) gives y³ − 2y + 1 = 0, which is cubic, so the given equation is not quadratic.

Q2(4). x + 1/x = −2

As written, it is a reciprocal equation. Multiplying by x (x ≠ 0) gives x² + 2x + 1 = 0. The transformed equation is quadratic, but the original is not written in quadratic-polynomial form.

Q2(5). (m + 2)(m − 5) = 0

Yes. Expanding gives m² − 3m − 10 = 0.

Q2(6). m³ + 3m² − 2 = 3m³

Rearranging gives 2m³ − 3m² + 2 = 0, which is cubic, not quadratic.

Q3(1). 2y = 10 − y²

y² + 2y − 10 = 0; a = 1, b = 2, c = −10.

Q3(2). (x − 1)² = 2x + 3

x² − 2x + 1 = 2x + 3 ⇒ x² − 4x − 2 = 0; a = 1, b = −4, c = −2.

Q3(3). x² + 5x = −(3 − x)

x² + 5x = −3 + x ⇒ x² + 4x + 3 = 0; a = 1, b = 4, c = 3.

Q3(4). 3m² = 2m² − 9

m² + 9 = 0; a = 1, b = 0, c = 9.

Q3(5). p(3 + 6p) = −5

6p² + 3p + 5 = 0; a = 6, b = 3, c = 5.

Q3(6). x² − 9 = 13

x² − 22 = 0; a = 1, b = 0, c = −22.

Q4(1). x² + 4x − 5 = 0; test x = 1 and −1

x = 1 gives 1 + 4 − 5 = 0, so it is a root. x = −1 gives 1 − 4 − 5 = −8, so it is not a root.

Q4(2). 2m² − 5m = 0; test m = 2 and 5/2

Factor: m(2m − 5) = 0. Roots are 0 and 5/2. Thus 2 is not a root; 5/2 is a root.

Q5. Find k if x = 3 is a root of kx² − 10x + 3 = 0

9k − 30 + 3 = 0 ⇒ 9k = 27 ⇒ k = 3.

Q6. One root of 5m² + 2m + k = 0 is −7/5

5(49/25) + 2(−7/5) + k = 0 ⇒ 49/5 − 14/5 + k = 0 ⇒ 7 + k = 0 ⇒ k = −7.

Q1(9). 2m(m − 24) = 50

m² − 24m − 25 = 0 ⇒ (m − 25)(m + 1) = 0 ⇒ m = 25, −1.

Q1(10). 25m² = 9

m² = 9/25 ⇒ m = ±3/5.

Q1(11). 7m² = 21m

Q1(12). m² − 11 = 0

8. Practice Set 2.6 — Applications

Q1. Product of Pragati’s age 2 years ago and 3 years hence is 84

Let present age be x. (x − 2)(x + 3) = 84 ⇒ x² + x − 90 = 0 ⇒ (x + 10)(x − 9) = 0. Reject negative age; present age = 9 years.

Q2. Sum of squares of two consecutive natural numbers is 244

As printed, consecutive integers n and n+1 give 2n²+2n+1=244, which has no integer solution. The pair 10 and 12 does satisfy 10²+12²=244, but these are consecutive even numbers, not consecutive natural numbers. Please verify the textbook wording.

Q3. 150 orange trees; trees per row are 5 more than per column

Let columns = x and rows = x+5. x(x+5)=150 ⇒ x²+5x−150=0 ⇒ (x+15)(x−10)=0. Reject negative value: 10 trees per column and 15 per row.

Q4. Vivek is 5 years older than Kishor; reciprocals sum to 1/6

Let Kishor’s age be x and Vivek’s x+5. 1/x + 1/(x+5) = 1/6 ⇒ x²−7x−30=0 ⇒ (x−10)(x+3)=0. Ages: Kishor 10, Vivek 15 years.

Q5. Second test score is 10 more; five times second score equals square of first

Let first score = x, second = x+10. x²=5(x+10) ⇒ x²−5x−50=0 ⇒ (x−10)(x+5)=0. Reject negative score: first 10, second 20.

Q6. Cost per pot is ₹40 more than 10 times the number of pots; total cost ₹600

Let number of pots be n; cost per pot c=10n+40. n(10n+40)=600 ⇒ n²+4n−60=0 ⇒ (n+10)(n−6)=0. Therefore n=6 pots and cost per pot = ₹100.

Q7. Boat travels 36 km downstream and back in 8 hours; still-water speed 12 km/h

Let current speed be c. 36/(12+c)+36/(12−c)=8 ⇒ 864/(144−c²)=8 ⇒ c²=36. Current speed = 6 km/h.

Q8. Pintu takes 6 days more than Nishu; together finish in 4 days

Let Nishu take x days and Pintu x+6. 1/x + 1/(x+6)=1/4 ⇒ x²−2x−24=0 ⇒ (x−6)(x+4)=0. Nishu takes 6 days; Pintu takes 12 days.

Q9. 460 divided by a natural number gives quotient 6 more than five times divisor and remainder 1

Let divisor d and quotient q=5d+6. 460=dq+1 ⇒ d(5d+6)=459 ⇒ 5d²+6d−459=0 ⇒ d=9 (reject negative root). Quotient = 5(9)+6 = 51.
