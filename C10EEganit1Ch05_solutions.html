Chapter 5: Probability

1. Chapter at a Glance

This chapter introduces the concept of probability, which is a mathematical way to express the possibility of an event occurring. The main topics covered are:

  • Random experiments and their outcomes.
  • Sample space and events.
  • Probability of an event.

Students will learn how to identify random experiments, list all possible outcomes in a sample space, define specific events as subsets of a sample space, and calculate the probability of those events using a mathematical formula.

2. Important Concepts Explained

Random Experiment

An experiment in which all possible results are known in advance, but none of them can be predicted with certainty, and there is an equal possibility for each result, is called a 'Random experiment'.

  • Examples: Tossing a coin, throwing a die, picking a card from a pack of well-shuffled playing cards.

Outcome

The result of a random experiment is known as an 'Outcome'.

  • Example: When tossing a coin, the outcomes are Head (H) or Tail (T).

Equally Likely Outcomes

A given number of outcomes are said to be equally likely if none of them occurs in preference to others. We assume that objects used for random experiments (like coins or dice) are fair or unbiased.

Sample Space

The set of all possible outcomes of a random experiment is called the sample space.

  • It is denoted by 'S' or '$\Omega$'.
  • Each element of the sample space is called a 'sample point'.
  • The number of elements in the set 'S' is denoted by $n(S)$.
  • If $n(S)$ is finite, it is a finite sample space.

Event

The outcomes satisfying a particular condition are called favourable outcomes. A set of favourable outcomes of a given sample space is an 'event'. An event is a subset of the sample space.

  • Events are denoted by capital letters like A, B, C, etc.
  • The number of elements in event A is denoted by $n(A)$.

4. Formulas, Rules, and Properties

Probability of an Event

If 'S' is the sample space and 'A' is an expected event, the probability of event A, denoted by $P(A)$, is given by:

$$P(A) = \frac{\text{Number of sample points in event A}}{\text{Number of sample points in sample space}} = \frac{n(A)}{n(S)}$$

Properties of Probability

  • Probability is expressed as a fraction or a percentage.
  • The probability of any event is between 0 and 1 (inclusive), or 0% to 100%.
  • If E is any event, $0 \le P(E) \le 1$ or $0\% \le P(E) \le 100\%$.

5. Worked Examples — Step by Step

Ex. (1) Find the probability of the following, when one coin is tossed.

(i) getting head (ii) getting tail

Solution:

  • Let 'S' be the sample space. $S = \{H, T\}$, so $n(S) = 2$.
  • (i) Let event A be getting head. $A = \{H\}$, so $n(A) = 1$.

$P(A) = \frac{n(A)}{n(S)} = \frac{1}{2}$

  • (ii) Let event B be getting tail. $B = \{T\}$, so $n(B) = 1$.

$P(B) = \frac{n(B)}{n(S)} = \frac{1}{2}$

Ex. (2) If one die is rolled then find the probability of each of the following events.

(i) Number on the upper face is prime (ii) Number on the upper face is even.

Solution:

  • 'S' is the sample space. $S = \{1, 2, 3, 4, 5, 6\}$, so $n(S) = 6$.
  • (i) Event A: Prime number on the upper face. $A = \{2, 3, 5\}$, so $n(A) = 3$.

$P(A) = \frac{n(A)}{n(S)} = \frac{3}{6} = \frac{1}{2}$

  • (ii) Event B: Even number on the upper face. $B = \{2, 4, 6\}$, so $n(B) = 3$.

$P(B) = \frac{n(B)}{n(S)} = \frac{3}{6} = \frac{1}{2}$

Ex. (3) A card is drawn from a well-shuffled pack of 52 playing cards. Find the probability of each event. The card drawn is (i) a red card (ii) a face card.

Solution:

  • $n(S) = 52$.
  • (i) Event A: Card drawn is a red card. Total red cards = 13 hearts + 13 diamonds = 26. $n(A) = 26$.

$P(A) = \frac{n(A)}{n(S)} = \frac{26}{52} = \frac{1}{2}$

  • (ii) Event B: Card drawn is a face card. Total face cards = 12. $n(B) = 12$.

$P(B) = \frac{n(B)}{n(S)} = \frac{12}{52} = \frac{3}{13}$

Ex. (4) A box contains 5 strawberry chocolates, 6 coffee chocolates and 2 peppermint chocolates. Find the probability of each of the following events, if one of the chocolates is picked at random. (i) it is a coffee chocolate (ii) it is a peppermint chocolate.

Solution:

  • $n(S) = 5 + 6 + 2 = 13$.
  • (i) Event A: it is a coffee chocolate. $n(A) = 6$.

$P(A) = \frac{n(A)}{n(S)} = \frac{6}{13}$

  • (ii) Event B: it is a peppermint chocolate. $n(B) = 2$.

$P(B) = \frac{n(B)}{n(S)} = \frac{2}{13}$

7. Important Questions and Answers

  • Q: Can the probability of an event be 1.5?

A: No, probability must be between 0 and 1.

  • Q: What is the probability of an impossible event?

A: 0.

  • Q: What is the probability of a sure event?

A: 1.

8. Common Errors and How to Avoid Them

  • Counting Errors: Always double-check the total number of outcomes in the sample space $n(S)$ before calculating probability.
  • Misinterpreting "At least/At most": "At least one head" means one or more heads. "At most one head" means zero or one head.
  • Simplifying Fractions: Always simplify the final probability fraction to its lowest terms.

9. Quick Revision Sheet

  • Sample Space (S): Set of all possible outcomes.
  • Event (A): Subset of sample space satisfying a condition.
  • Probability Formula: $P(A) = \frac{n(A)}{n(S)}$.
  • Range: $0 \le P(A) \le 1$.
