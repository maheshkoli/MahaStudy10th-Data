A. Core Concepts and Formulae

Linear equation in two variables

General form: ax + by + c = 0, where a, b and c are real numbers and a and b are not both zero. Each variable must have degree 1.

Simultaneous equations

Two equations considered together. Their common ordered pair (x, y) must satisfy both equations.

Elimination method

Multiply one or both equations so that the coefficients of one variable become equal or opposite. Add or subtract the equations, solve for one variable, then substitute to find the other.

Graphical method

Each linear equation represents a straight line. The intersection point is the solution. Coincident lines give infinitely many solutions; parallel distinct lines give no solution.

Determinant

For a 2 × 2 determinant, | a b ; c d | = ad − bc.

Cramer's Rule

For a₁x + b₁y = c₁ and a₂x + b₂y = c₂: D = a₁b₂ − a₂b₁; Dₓ = c₁b₂ − c₂b₁; Dᵧ = a₁c₂ − a₂c₁. If D ≠ 0, x = Dₓ/D and y = Dᵧ/D.

Reducible equations

Use substitutions such as m = 1/x and n = 1/y, or a = 1/(x − y) and b = 1/(x + y), to convert a suitable system into linear equations. Check that no denominator is zero.

Graph plotting tip

Choose convenient values that give integer coordinates when possible. Plot at least four ordered pairs and verify that they lie on one straight line.

B. Textbook Worked Examples

Example: 5x − 3y = 8; 3x + y = 2

Multiply the second equation by 3: 9x + 3y = 6. Add to the first equation: 14x = 14, so x = 1. Substitute into 3x + y = 2: 3 + y = 2, so y = −1. Answer: (x, y) = (1, −1).

Example: 3x + 2y = 29; 5x − y = 18

Multiply the second equation by 2: 10x − 2y = 36. Add to the first: 13x = 65, so x = 5. Then 15 + 2y = 29, so y = 7. Answer: (5, 7).

Example: 15x + 17y = 21; 17x + 15y = 11

Add: 32x + 32y = 32, so x + y = 1. Subtract the second equation from the first: −2x + 2y = 10, so −x + y = 5. Add these reduced equations: 2y = 6, so y = 3 and x = −2. Answer: (−2, 3).

Graph example: x + y = 4; 2x − y = 2

Adding the equations gives 3x = 6, so x = 2. Then y = 2. The lines intersect at (2, 2).

Cramer's Rule example: 5x + 3y = −11; 2x + 4y = −10

D = 5(4) − 2(3) = 14. Dₓ = (−11)(4) − (−10)(3) = −14. Dᵧ = 5(−10) − 2(−11) = −28. Therefore x = −14/14 = −1 and y = −28/14 = −2.

Cramer's activity: 2x + y = 19; 2x − 3y = −3

D = 2(−3) − 2(1) = −8. Dₓ = 19(−3) − (−3)(1) = −54. Dᵧ = 2(−3) − 2(19) = −44. Hence x = 27/4 and y = 11/2. Check: these values satisfy both equations.

Transformation example: 4/x + 5/y = 7; 3/x + 4/y = 5

Let m = 1/x and n = 1/y. Then 4m + 5n = 7 and 3m + 4n = 5. Solving gives m = 3 and n = −1. Therefore x = 1/3 and y = −1.

Transformation example: 4/(x − y) + 1/(x + y) = 3; 2/(x − y) − 3/(x + y) = 5

Let a = 1/(x − y), b = 1/(x + y). Then 4a + b = 3 and 2a − 3b = 5. Solving gives a = 1, b = −1. Thus x − y = 1 and x + y = −1. Adding gives 2x = 0, so x = 0 and y = −1.

E. Practice Set 1.3 — Determinants and Cramer's Rule

Q1. Complete determinant |3 2; 4 5|

Value = 3 × 5 − 2 × 4 = 15 − 8 = 7.

Q2(1). |−1 7; 2 4|

Value = (−1)(4) − (7)(2) = −4 − 14 = −18.

Q2(2). |5 3; −7 0|

Value = 5(0) − 3(−7) = 21.

Q2(3). |7/3 5/3; 3/2 1/2|

Value = (7/3)(1/2) − (5/3)(3/2) = 7/6 − 15/6 = −8/6 = −4/3.

Q3(1). 3x − 4y = 10; 4x + 3y = 5

D = 3(3) − 4(−4) = 25. Dₓ = 10(3) − 5(−4) = 50. Dᵧ = 3(5) − 4(10) = −25. Hence x = 2, y = −1.

Q3(2). 4x + 3y − 4 = 0; 6x = 8 − 5y

Rewrite as 4x + 3y = 4 and 6x + 5y = 8. D = 4(5) − 6(3) = 2. Dₓ = 4(5) − 8(3) = −4. Dᵧ = 4(8) − 6(4) = 8. Hence x = −2, y = 4.

Q3(3). x + 2y = −1; 2x − 3y = 12

D = 1(−3) − 2(2) = −7. Dₓ = (−1)(−3) − 12(2) = −21. Dᵧ = 1(12) − 2(−1) = 14. Hence x = 3, y = −2.

Q3(4). 6x − 4y = −12; 8x − 3y = −2

D = 6(−3) − 8(−4) = 14. Dₓ = (−12)(−3) − (−2)(−4) = 28. Dᵧ = 6(−2) − 8(−12) = 84. Hence x = 2, y = 6.

Q3(5). 4m + 6n = 54; 3m + 2n = 28

D = 4(2) − 3(6) = −10. Dₘ = 54(2) − 28(6) = −60. Dₙ = 4(28) − 3(54) = −50. Hence m = 6, n = 5.

G. Application Examples from the Textbook

Rectangle: perimeter 40 cm; length is 2 cm more than twice breadth

Let length = x and breadth = y. 2(x + y) = 40 gives x + y = 20. Also x = 2y + 2, so x − 2y = 2. Solving gives x = 14 and y = 6. Length = 14 cm; breadth = 6 cm.

Watch sale

Let analogue watch price = x and digital watch price = y. 11x + 6y = 4330; 22x + 5y = 7330. Double the first: 22x + 12y = 8660. Subtract the second equation: 7y = 1330, so y = ₹190. Then 11x + 1140 = 4330, so x = ₹290.

Boat and current

Let boat speed in still water = x km/h and current speed = y km/h. Upstream speed = x − y; downstream speed = x + y. The textbook reduces the time equations using m = 1/(x − y), n = 1/(x + y), obtaining x − y = 4 and x + y = 12. Thus x = 8 km/h and y = 4 km/h.

Distribution among students

Let x be the number of students and ₹y be the original share per student. (x + 10)(y − 2) = xy gives −x + 5y = 10. (x − 15)(y + 6) = xy gives 2x − 5y = 30. Add: x = 40. Then y = 10. Total = xy = ₹400.

Three-digit number

Let hundreds digit = x, units digit = y, and middle digit = x + y + 1. The number is 110x + 11y + 10 and digit sum is 2x + 2y + 1. The first condition gives 76x − 23y = 7. Reversing the digits adds 198, giving x − y = −2, so x = y − 2. Substitute: 76(y − 2) − 23y = 7, so y = 3 and x = 1. Middle digit = 5. Number = 153.

H. Practice Set 1.5 — Word Problems

Q1. Two numbers differ by 3; twice the smaller plus thrice the greater is 19

Let smaller = s and greater = g. g − s = 3 and 2s + 3g = 19. Substitute g = s + 3: 2s + 3(s + 3) = 19, so 5s = 10 and s = 2; g = 5.

Q2. Rectangle sides shown in the figure

Opposite sides are equal: 2x + y + 8 = 4x − y and 2y = x + 4. The first gives x − y = 4; the second gives x = 2y − 4. Solving gives y = 8 and x = 12. Side lengths: 2x + y + 8 = 40 and 2y = 16; this does not produce equal opposite sides with the labels as extracted, so the figure labels need verification before perimeter and area can be trusted.

Q3. Father and son ages

Let father's age = f and son's age = s. f + 2s = 70 and 2f + s = 95. Double the first: 2f + 4s = 140. Subtract the second: 3s = 45, so s = 15 and f = 40. Father = 40 years; son = 15 years.

Q4. Fraction denominator

Let numerator = n and denominator = d. d = 2n + 4. After reducing both by 6, d − 6 = 12(n − 6). Substitute: 2n − 2 = 12n − 72, so 70 = 10n and n = 7. Then d = 18. Fraction = 7/18.

Q5. Box weights; truck capacity 10 tons

Let weights of boxes A and B be a and b tons. 150a + 100b = 10 and 260a + 40b = 10. Simplify: 3a + 2b = 0.2 and 13a + 2b = 0.5. Subtract: 10a = 0.3, so a = 0.03 ton = 30 kg. Then 2b = 0.11, so b = 0.055 ton = 55 kg.

Q6. Bus and aeroplane journey

Let bus distance = d km; plane distance = 1900 − d km. d/60 + (1900 − d)/700 = 5. Multiply by 2100: 35d + 3(1900 − d) = 10500. Thus 32d = 4800 and d = 150 km. Vishal travelled 150 km by bus.

Q7(1). Two-digit number and reversed number sum to 143; units digit is 3 more than tens digit

Let units digit = x and tens digit = y. 10y + x + 10x + y = 143, so 11(x + y) = 143 and x + y = 13. Also x − y = 3. Add: 2x = 16, so x = 8 and y = 5. Original number = 10y + x = 58.

Q7(2). Tea, sugar and rickshaw fare

Let tea cost ₹t/kg and sugar cost ₹s/kg. (3/2)t + 5s + 50 = 700, so 3t + 10s = 1300. Also 2t + 7s = 880. Multiply the first simplified equation by 2: 6t + 20s = 2600; multiply the second by 3: 6t + 21s = 2640. Thus s = ₹40/kg. Then 2t + 280 = 880, so t = ₹300/kg.

Q7(3). Notes of ₹10 and ₹50

Let x be the number of ₹10 notes and y the number of ₹50 notes. The first condition gives 10x + 50y = 2500. If the counts are interchanged and the amount is ₹500 less, then 50x + 10y = 2000. These equations give x = 125/4 and y = 175/4, which are not whole numbers. Q7(4). Present ages of Manish and Savita

Substituting M = 31 − S gives 28 − S = 4S, so S = 28/5 = 5.6 and M = 127/5 = 25.4. Q7(5). Daily wages in ratio 5 : 3; total ₹720

Let wages be 5k and 3k. 8k = 720, so k = 90. Skilled worker = ₹450/day; unskilled worker = ₹270/day.

Q7(6). Two bikers 30 km apart

Let Hamid's speed be H and Joseph's speed be J km/h. Meeting after 20 minutes = 1/3 hour while riding towards each other gives H + J = 30 ÷ (1/3) = 90. If Joseph rides away in the opposite direction and Hamid catches him after 3 hours, H − J = 30/3 = 10. Add: 2H = 100, so H = 50; J = 40. Hamid = 50 km/h; Joseph = 40 km/h.
