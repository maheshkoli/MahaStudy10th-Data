Chapter 3: Arithmetic Progression

1. Chapter at a Glance

This chapter introduces the concept of sequences and specifically focuses on Arithmetic Progressions (A.P.). Students will learn to identify sequences, determine if a sequence is an A.P., find the $n^{th}$ term of an A.P., and calculate the sum of the first $n$ terms of an A.P. The chapter also covers applications of A.P. in real-life scenarios.

2. Important Concepts Explained

Sequence

A set of numbers arranged in a definite order is called a sequence. If the numbers are written as $t_1, t_2, t_3, \dots, t_n, \dots$, then $t_n$ represents the term at the $n^{th}$ position.

Arithmetic Progression (A.P.)

An A.P. is a sequence where the difference between two consecutive terms is constant. This constant difference is called the common difference and is denoted by '$d$'.

  • If the difference $t_{n+1} - t_n = d$ is constant, the sequence is an A.P.
  • The first term is denoted by '$a$'.
  • The terms of an A.P. are: $a, (a+d), (a+2d), (a+3d), \dots$

$n^{th}$ Term of an A.P.

The formula to find the $n^{th}$ term ($t_n$) of an A.P. is:

$$t_n = a + (n - 1)d$$

Where:

  • $a$ = first term
  • $d$ = common difference
  • $n$ = position of the term

Sum of First $n$ Terms of an A.P. ($S_n$)

The sum of the first $n$ terms is denoted by $S_n$.

  • Formula 1: $S_n = \frac{n}{2} [2a + (n - 1)d]$
  • Formula 2: $S_n = \frac{n}{2} [t_1 + t_n]$ (where $t_1$ is the first term and $t_n$ is the last term)

3. Definitions and Key Terms

  • Sequence: A set of numbers arranged in a definite order.
  • Arithmetic Progression (A.P.): A sequence where the difference between consecutive terms is constant.
  • Common Difference ($d$): The constant difference between consecutive terms in an A.P. ($d = t_{n+1} - t_n$).
  • First Term ($a$): The first number in the sequence ($t_1$).
  • Finite A.P.: An A.P. with a limited number of terms.
  • Infinite A.P.: An A.P. with an unlimited number of terms.

4. Formulas, Rules, and Properties

  1. Common Difference: $d = t_{n+1} - t_n$
  2. $n^{th}$ Term: $t_n = a + (n - 1)d$
  3. Sum of $n$ terms: $S_n = \frac{n}{2} [2a + (n - 1)d]$
  4. Sum using first and last term: $S_n = \frac{n}{2} [t_1 + t_n]$
  5. Sum of first $n$ natural numbers: $S_n = \frac{n(n+1)}{2}$
  6. Sum of first $n$ even natural numbers: $S_n = n(n+1)$
  7. Sum of first $n$ odd natural numbers: $S_n = n^2$

Ex (1) from page 68: Which of the following sequences are A.P.? If it is an A.P., find the next two terms.

(i) 5, 12, 19, 26, ...

  • Solution:
  • $t_1 = 5, t_2 = 12, t_3 = 19, t_4 = 26$
  • $t_2 - t_1 = 12 - 5 = 7$
  • $t_3 - t_2 = 19 - 12 = 7$
  • Since the difference is constant ($d = 7$), it is an A.P.
  • Next two terms: $26 + 7 = 33$ and $33 + 7 = 40$.

Ex (1) from page 78: Find the sum of first 100 terms of A.P. 14, 16, 18, ...

  • Solution:
  • $a = 14, d = 2, n = 100$
  • $S_n = \frac{n}{2} [2a + (n - 1)d]$
  • $S_{100} = \frac{100}{2} [2(14) + (100 - 1)2]$
  • $S_{100} = 50 [28 + 99 \times 2] = 50 [28 + 198] = 50 \times 226 = 11300$.

(Selected solutions)

(1) 2, 4, 6, 8, ...

  • $t_3 - t_2 = 6 - 4 = 2$

  • $t_2 - t_1 = 0.33 - 0.3 = 0.03$
  • $t_3 - t_2 = 0.0333 - 0.33 = -0.2967$

2. Write an A.P. whose first term is $a$ and common difference is $d$.

(1) $a = 10, d = 5$

  • $t_1 = 10$
  • $t_2 = 10 + 5 = 15$
  • $t_3 = 15 + 5 = 20$
  • $t_4 = 20 + 5 = 25$
  • Answer: 10, 15, 20, 25, ...

Practice Set 3.2 (Page 75)

2. Decide whether following sequence is an A.P., if so find the 20th term.

-12, -5, 2, 9, 16, 23, 30, ...

  • $a = -12, d = -5 - (-12) = 7$
  • $t_n = a + (n - 1)d$
  • $t_{20} = -12 + (20 - 1)7 = -12 + 19 \times 7 = -12 + 133 = 121$.
  • Answer: Yes, 20th term is 121.

Practice Set 3.3 (Page 81)

1. First term and common difference are 6 and 3; find $S_{27}$.

  • $a = 6, d = 3, n = 27$
  • $S_n = \frac{n}{2} [2a + (n - 1)d]$
  • $S_{27} = \frac{27}{2} [2(6) + (27 - 1)3] = \frac{27}{2} [12 + 26 \times 3] = \frac{27}{2} [12 + 78] = \frac{27}{2} \times 90 = 27 \times 45 = 1215$.
  • Answer: 1215.

7. Important Questions and Answers

  • Q: Can the common difference of an A.P. be negative?
  • A: Yes, for example in the sequence 10, 8, 6, 4, ..., $d = -2$.
  • Q: What is the difference between a sequence and an A.P.?
  • A: A sequence is any ordered set of numbers. An A.P. is a specific type of sequence where the difference between consecutive terms is constant.

8. Common Errors and How to Avoid Them

  • Error: Forgetting to subtract 1 from $n$ in the $t_n$ formula.
  • Correction: Always use $(n-1)$ because the first term does not have $d$ added to it.
  • Error: Incorrectly calculating $d$ when terms are negative.
  • Correction: Always calculate $d = t_2 - t_1$ carefully using brackets, e.g., $-5 - (-12) = -5 + 12 = 7$.
