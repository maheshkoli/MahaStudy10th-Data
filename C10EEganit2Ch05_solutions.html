Chapter 5: Co-ordinate Geometry

1. Chapter at a Glance

This chapter introduces the fundamental concepts of Co-ordinate Geometry. Students will learn how to calculate the distance between two points in a plane, how to find the coordinates of a point that divides a line segment in a given ratio, and how to determine the slope of a line. These concepts are essential for analyzing geometric figures using algebraic methods.

2. Important Concepts Explained

Distance between two points on an axis

  • On X-axis: If points $A(x_1, 0)$ and $B(x_2, 0)$ are on the X-axis, the distance $d(A, B) = |x_2 - x_1|$.
  • On Y-axis: If points $P(0, y_1)$ and $Q(0, y_2)$ are on the Y-axis, the distance $d(P, Q) = |y_2 - y_1|$.

Distance between two points parallel to axes

  • If a segment is parallel to the X-axis, the Y-coordinates of its endpoints are equal. The distance is the difference between the X-coordinates.
  • If a segment is parallel to the Y-axis, the X-coordinates of its endpoints are equal. The distance is the difference between the Y-coordinates.

Distance Formula

The distance between two points $A(x_1, y_1)$ and $B(x_2, y_2)$ in the XY-plane is given by:

$$d(A, B) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$$

  • Distance from Origin: If point $P$ has coordinates $(x, y)$, its distance from the origin $O(0, 0)$ is $d(O, P) = \sqrt{x^2 + y^2}$.

Section Formula

If point $P(x, y)$ divides the line segment joining $A(x_1, y_1)$ and $B(x_2, y_2)$ in the ratio $m : n$, the coordinates of $P$ are:

$$x = \frac{mx_2 + nx_1}{m + n}, \quad y = \frac{my_2 + ny_1}{m + n}$$

Midpoint Formula

If $P(x, y)$ is the midpoint of the segment joining $A(x_1, y_1)$ and $B(x_2, y_2)$, then $m = n = 1$. The coordinates are:

$$x = \frac{x_1 + x_2}{2}, \quad y = \frac{y_1 + y_2}{2}$$

Centroid Formula

If $G(x, y)$ is the centroid of a triangle with vertices $A(x_1, y_1)$, $B(x_2, y_2)$, and $C(x_3, y_3)$, the coordinates are:

$$x = \frac{x_1 + x_2 + x_3}{3}, \quad y = \frac{y_1 + y_2 + y_3}{3}$$

Slope of a Line

The slope ($m$) of a line passing through points $(x_1, y_1)$ and $(x_2, y_2)$ is:

$$m = \frac{y_2 - y_1}{x_2 - x_1}$$

  • Slope of X-axis: 0.
  • Slope of Y-axis: Undefined (division by zero).
  • Parallel Lines: Parallel lines have equal slopes.
  • Trigonometric relation: If a line makes an angle $\theta$ with the positive direction of the X-axis, its slope $m = \tan \theta$.

3. Definitions and Key Terms

  • Collinear Points: Three or more points that lie on the same straight line.
  • Centroid: The point of concurrence of the medians of a triangle. It divides each median in the ratio 2:1.
  • Circumcentre: The point of concurrence of the perpendicular bisectors of the sides of a triangle. It is equidistant from the vertices.
  • Trisection: Dividing a line segment into three equal parts.

4. Formulas, Rules, and Properties

  • Distance Formula: $d = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}$
  • Section Formula: $P(x, y) = \left( \frac{mx_2 + nx_1}{m + n}, \frac{my_2 + ny_1}{m + n} \right)$
  • Midpoint Formula: $P(x, y) = \left( \frac{x_1 + x_2}{2}, \frac{y_1 + y_2}{2} \right)$
  • Centroid Formula: $G(x, y) = \left( \frac{x_1 + x_2 + x_3}{3}, \frac{y_1 + y_2 + y_3}{3} \right)$
  • Slope Formula: $m = \frac{y_2 - y_1}{x_2 - x_1} = \tan \theta$

6. Exercise / Practice Set Solutions

Practice Set 5.1

1. Find the distance between each of the following pairs of points.

(Solutions follow the distance formula $d = \sqrt{(x_2-x_1)^2 + (y_2-y_1)^2}$)

(1) $A(2, 3), B(4, 1)$: $d = \sqrt{(4-2)^2 + (1-3)^2} = \sqrt{2^2 + (-2)^2} = \sqrt{4+4} = \sqrt{8} = 2\sqrt{2}$

(2) $P(-5, 7), Q(-1, 3)$: $d = \sqrt{(-1 - (-5))^2 + (3-7)^2} = \sqrt{4^2 + (-4)^2} = \sqrt{16+16} = \sqrt{32} = 4\sqrt{2}$

(3) $R(0, -3), S(0, 5/2)$: $d = \sqrt{(0-0)^2 + (5/2 - (-3))^2} = \sqrt{(5/2 + 6/2)^2} = \sqrt{(11/2)^2} = 11/2$

(4) $L(5, -8), M(-7, -3)$: $d = \sqrt{(-7-5)^2 + (-3 - (-8))^2} = \sqrt{(-12)^2 + 5^2} = \sqrt{144+25} = \sqrt{169} = 13$

(5) $T(-3, 6), R(9, -10)$: $d = \sqrt{(9 - (-3))^2 + (-10-6)^2} = \sqrt{12^2 + (-16)^2} = \sqrt{144+256} = \sqrt{400} = 20$

(6) $W(-7/2, 4), X(11, 4)$: $d = \sqrt{(11 - (-7/2))^2 + (4-4)^2} = \sqrt{(22/2 + 7/2)^2} = \sqrt{(29/2)^2} = 29/2$

2. Determine whether the points are collinear.

(Check if $d(A, B) + d(B, C) = d(A, C)$)

(1) $A(1, -3), B(2, -5), C(-4, 7)$: $d(AB) = \sqrt{5}, d(BC) = \sqrt{180} = 6\sqrt{5}, d(AC) = \sqrt{125} = 5\sqrt{5}$. Since $\sqrt{5} + 5\sqrt{5} = 6\sqrt{5}$, they are collinear.

(2) $L(-2, 3), M(1, -3), N(5, 4)$: Not collinear.

(3) $R(0, 3), D(2, 1), S(3, -1)$: $d(RD) = \sqrt{8} = 2\sqrt{2}, d(DS) = \sqrt{5}, d(RS) = \sqrt{25} = 5$. Not collinear.

(4) $P(-2, 3), Q(1, 2), R(4, 1)$: $d(PQ) = \sqrt{10}, d(QR) = \sqrt{10}, d(PR) = \sqrt{40} = 2\sqrt{10}$. Since $\sqrt{10} + \sqrt{10} = 2\sqrt{10}$, they are collinear.

3. Find the point on the X-axis which is equidistant from $A(-3, 4)$ and $B(1, -4)$.

Let the point be $P(x, 0)$. $PA^2 = PB^2$.

$(x - (-3))^2 + (0 - 4)^2 = (x - 1)^2 + (0 - (-4))^2$

$x^2 + 6x + 9 + 16 = x^2 - 2x + 1 + 16$

$8x = -8 \Rightarrow x = -1$. Point is $(-1, 0)$.

4. Verify that points $P(-2, 2), Q(2, 2)$ and $R(2, 7)$ are vertices of a right angled triangle.

$PQ^2 = 4^2 + 0^2 = 16$

$QR^2 = 0^2 + 5^2 = 25$

$PR^2 = (2 - (-2))^2 + (7 - 2)^2 = 4^2 + 5^2 = 16 + 25 = 41$

Since $PQ^2 + QR^2 = 16 + 25 = 41 = PR^2$, it is a right-angled triangle.

7. Important Questions and Answers

  • Q: What is the slope of a line parallel to the Y-axis?

A: The slope cannot be determined (it is undefined) because the change in X is zero.

  • Q: How do you check if a quadrilateral is a parallelogram using coordinates?

A: Calculate the slopes of all four sides. If the slopes of opposite sides are equal, the quadrilateral is a parallelogram.

8. Common Errors and How to Avoid Them

  • Sign Errors: Always be careful with negative signs when using the distance formula, especially when subtracting a negative coordinate (e.g., $x_2 - (-x_1) = x_2 + x_1$).
  • Formula Confusion: Ensure you use the correct formula for the specific task (e.g., do not use the midpoint formula when the section formula is required for a ratio other than 1:1).
